# 人格图鉴 · 软文素材台

给「虾说说」用的发帖文案页。每天三张卡片：早软、午软、晚硬广。手机打开就能复制。

预备区间：**2026-11-15 至 2026-12-31**。软文只用历史人物；分院帽只出现在硬广。后续日期在 `tools/gen-winter.py` 生成 `js/data-winter.js`。

## 本地

双击 `index.html`，或：

```bash
npx --yes serve .
```

## 部署

GitHub Pages。地址预计：`https://chenzyishere.github.io/xhs-copy/`

11/15–11/21 在 [js/data.js](js/data.js)，11/22–12/31 在 [js/data-winter.js](js/data-winter.js)。
